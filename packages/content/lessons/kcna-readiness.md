KCNA is a knowledge exam covering Kubernetes and cloud native fundamentals. The weight is broad: fundamentals, orchestration, delivery, architecture, observability, and the CNCF ecosystem. Passing requires vocabulary and mental models, not only command recall.

Prepare by explaining each core object in one minute: what it is, why it exists, which component owns it, and what a common failure looks like. Then connect tools to layers: container runtime, CNI, CSI, ingress, DNS, GitOps, and observability. The cloud native landscape matters because KCNA asks where projects fit.

Use the readiness dashboard to find weak domains. A high lesson count is not the same as exam evidence, so take the 60-question mock and review every missed explanation. Record the domain of each miss and return to the mapped lesson.

Failure modes: memorising commands without understanding ownership, skipping the CNCF ecosystem, and assuming a single mock score proves readiness. Verification: explain a Pod, Service, and Deployment without notes, then score above the threshold on two different mock runs.

CoreDNS serves names like `web.demo.svc.cluster.local`. Pods resolve Services through the cluster DNS service.

- `<service>.<namespace>.svc.cluster.local`
- A Pod in the same namespace can use the short name: `web`.
- Headless Services expose Pod IPs directly.
- DNS failures often look like connection timeouts.

```bash
kubectl create deployment web --image=nginx --replicas=2 -n demo
kubectl expose deployment web --port=80 -n demo
kubectl run client --image=busybox -n demo
kubectl exec client -n demo -- nslookup web
```

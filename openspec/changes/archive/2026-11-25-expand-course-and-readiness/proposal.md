# Proposal

## Why

The course now covers the core path, but CKAD and CKS still need more multi-resource
practice, all lesson quizzes need rationales, KCNA/KCSA banks can be broader, and
readiness should communicate sample confidence and change since the last attempt.

## What Changes

- Add multi-resource CKAD and CKS tasks plus additional CKA/CKAD/CKS incidents.
- Add authored explanations to every lesson quiz question.
- Expand KCNA and KCSA question coverage for ecosystem, threat, compliance, and runtime topics.
- Add readiness confidence and evidence sample size.
- Add a last-attempt score-change indicator.
- Normalize standard Deployment pod templates and envFrom references on apply.
- Update the objective audit and tests.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `certification`: broader task pools, quiz rationales, readiness confidence/change.
- `content-authoring`: complete quiz explanations and objective audit coverage.
- `cluster-simulator`: standard pod template and envFrom normalization.

## Impact

- Content task seeds, exam pool, roadmap data, simulator apply behavior.
- Certification dashboard and exam review UI.
- Tests and docs.

# Proposal

## Why

The content review found that short task drills and a fixed 60-question selection
left the 100-question banks underused and did not prepare learners for longer
multi-resource exam scenarios.

## What Changes

- Add five capstone tasks per hands-on track.
- Grow every hands-on pool from 25 to 30 tasks.
- Rotate the selected 60 knowledge questions on each exam attempt.
- Map every capstone task into certification domains.

## Impact

- Certification task catalog, domain mappings, exam selection, tests, and docs.

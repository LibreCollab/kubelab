# Design

- Add `format`, `questionCount`, duration, and passing metadata per track.
- Knowledge tracks select 60 rotated questions from the global eligible pool.
- Hands-on tracks expose no knowledge exam and use 15-task pools assembled from technical task seeds.
- CKA/CKAD pools combine CKA, CKAD, and CKS tasks; CKS adds KCSA security tasks.
- Exam route explains hands-on-only mode and links to the lab runner.
- Roadmap shows only the applicable exam entry point.

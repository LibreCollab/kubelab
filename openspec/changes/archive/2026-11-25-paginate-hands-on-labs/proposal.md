# Proposal

## Why

The hands-on runner lists all 15 tasks in one sidebar, making the page long and
hard to navigate. It should match the knowledge exam's paged flow.

## What Changes

- Show five tasks per page.
- Add Previous/Next task-page controls.
- Show Submit only on the final task page.
- Keep terminal state and answers while changing pages.
- Remove the long task preview from the intro screen.
- Update E2E coverage.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `certification`: paged hands-on task navigation.

## Impact

- Lab runner UI, styles, and tests.
